# Travel Fare Calculator
This program calculates the total travel fare for passengers based on distance and a set fare rate.

## Program Specifications

### Version 1
Description: A simple program that takes user inputs and calculates the total fare.

Inputs: Passenger name, distance in km, and number of passengers.

Processes: Multiplies distance by the fare rate (14) and the number of passengers.

Outputs: Prints the passenger name and the total fare.

### Version 2
Description: Updated the program to include input validation to handle bad user inputs.

Validation Rules:

Passenger name cannot be left blank.

Distance must be a positive number greater than 0.

Number of passengers must be a whole number greater than 0.

Added try-except blocks to stop the program from crashing if a user types letters instead of numbers.
